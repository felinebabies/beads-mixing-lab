# beads-mixing-lab

赤と緑のビーズを同数ずつ混ぜ、ランダムな配置にも生まれる偶然のむらを観察する小さな実験です。

`index.html` 一つで動作します。外部ライブラリや通信は不要で、ダウンロードしてオフラインでも使えます。混合・一時停止・リセット・一様シャッフル、粒数・速度・倍率の調整に対応しています。

粒を固定位置の間で交換する配置のモデルであり、重力・衝突・付着を再現する物理シミュレーションではありません。一様シャッフルは Web Crypto の乱数と Fisher–Yates 法を使います。同色隣接率は上下左右の直接隣接ペアについて計算し、混合完了の判定には使いません。

公開デモ: [混ざりかたの観察室](https://felinebabies.github.io/beads-mixing-lab/)
